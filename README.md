# Portfólio Web - GAC116 Programação Web

## Estrutura
- `/bootstrap`: Versão da página construída com o framework Bootstrap 5.
- `/outro-framework`: Versão equivalente construída com Tailwind CSS.

## Requisitos Atendidos
- Desenvolvido em HTML, CSS e JavaScript.
- Totalmente funcional e responsivo.
- Funcionalidade de tema claro/escuro via JavaScript.
- Duas versões de frameworks implementadas com conteúdos idênticos.
